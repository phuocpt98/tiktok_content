# Phase 5: Review and Publish

## Context Links
- [TikTok Content Posting API](https://developers.tiktok.com/products/content-posting-api/)
- [TikTok Shop Affiliate Vietnam](https://seller-vn.tiktok.com/university/essay?knowledge_id=8659790494680849)

## Overview
Human review queue for generated videos before posting. Phase 1 is manual posting with organized output. Phase 2 (later) adds TikTok API auto-posting.

## Key Insights from Research

### TikTok Content Posting API
- Requires developer app registration + audit
- Unaudited apps can only post as PRIVATE (not public)
- Supports: FILE_UPLOAD and PULL_FROM_URL methods
- Must pass TikTok's Terms of Service audit for public posting
- **Recommendation**: Start with manual posting, apply for API access in parallel

### TikTok Shop Affiliate (Vietnam)
- Creator needs 1,000+ followers for external product linking
- Two modes: Open Collaboration (public) and Target Collaboration (private)
- Commission: 5-30% per sale depending on product/seller
- Products must be listed on TikTok Shop first
- Creator selects products from TikTok Shop marketplace

### Practical Workflow (Phase 1)
1. Generate video -> save to `data/output/`
2. Review in file explorer / video player
3. Manually upload to TikTok via app
4. Add affiliate product link manually in TikTok app
5. Add hashtags and description (generated by system)

## Requirements

### Functional (Phase 1 - Manual)
- Review queue: list pending videos with metadata
- Approve/reject/redo workflow
- Generate posting metadata (title, description, hashtags)
- Organize approved videos for easy manual upload
- Generate posting schedule suggestions

### Functional (Phase 2 - Semi-Auto, Later)
- TikTok API integration for uploading
- Schedule posts
- Track post performance

### Non-Functional

- Open video in default player for review

## Implementation Steps

### 1. Review Queue Manager (`reviewer.py`)
```python
class ReviewQueue:
    def list_pending() -> list[VideoProject]
    def review(project_id) -> None  # opens video + shows metadata
    def approve(project_id) -> None  # move to approved/
    def reject(project_id, reason) -> None  # move to rejected/
    def redo(project_id) -> None  # regenerate with tweaks
```

### 2. Metadata Generator (`metadata.py`)
- Generate title from script hook
- Generate description with product info + CTA
- Generate hashtags (product + trending + channel-specific)
- Always include: #taphoapelpel #review
- Suggest best posting time

### 3. Scheduler (`scheduler.py`)
- Simple rule-based scheduler
- Input: list of approved videos
- Output: suggested posting times (VN timezone UTC+7)
- Respect minimum gap between posts (4h)
- Prioritize peak hours

### 4. CLI Commands
```bash
pel review list              # show pending videos
pel review show <id>         # open video + metadata
pel review approve <id>      # move to approved
pel review reject <id>       # move to rejected
pel review redo <id>         # regenerate
pel publish schedule         # show posting schedule
pel publish copy-meta <id>   # copy description+hashtags to clipboard
```

### 5. Clipboard helper
- `pel publish copy-meta <id>` copies formatted description + hashtags
- Ready to paste into TikTok app
- Saves time on manual posting

### 6. (Phase 2 - Later) TikTok API Integration
